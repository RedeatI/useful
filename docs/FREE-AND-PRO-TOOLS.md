# 免费与专业工具分层

## 原则

1. **基础工具永久免费**：Base64、UUID、JSON 等基础能力不付费
2. **免费工具无需登录**
3. **免费工具不因订阅失效停止运行**
4. **付费只控制官方源下载、更新和云服务**
5. **已下载本地工具取消订阅后继续运行**
6. **第三方源可以提供自己的替代工具**
