# Useful 0.1.0-beta.11 candidate

> **UNRELEASED CANDIDATE / NOT A DOWNLOAD PAGE.** This note records the intended beta scope. The

> checksum record.

Intended Release: [`v0.1.0-beta.11`](https://github.com/RedeatI/useful/releases/tag/v0.1.0-beta.11).

## Intended scope

- Release workflow scope: `desktop-lite` on the `beta` channel.
- Unsigned, development-trust Windows Setup Lite and Portable Lite previews.
- Source and the cross-platform Agent Kit.
- No Portable Full asset until the exact GPL corresponding-source and license Owner Gate passes.
- No macOS or Linux desktop package in this Release asset set.
- No signed-installer, notarization, production-update-feed, or supported-platform claim.

## Highlights

- Restores the in-app media component installer for Windows x64 without bundling large runtimes in
  the Lite desktop assets.
- Pins mpv `v0.41.0` to the official mpv project GitHub Release and pins FFmpeg `8.1.2` Essentials
  to the Windows build source linked from `ffmpeg.org`.
- Verifies each archive and selected executable by exact size and SHA-256 before atomically
  activating a versioned runtime; damaged or tampered installations fail closed.
- Keeps download URLs, provider identities, redirects, archive contents, and installed file sets
  closed to the compiled source lock rather than accepting renderer-supplied locations.
- Aligns the AV1 software fallback with the pinned FFmpeg build by using `libaom-av1`.
