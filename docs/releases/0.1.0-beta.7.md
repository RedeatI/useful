- Carries forward the desktop-lite release closure and beta.6 Compose dependency repair.
- Fixes the non-Windows bootstrap Clippy error found by the beta.6 tag dry-run.

  platform-specific lint failures are caught before an immutable tag is created.
- Keeps the Useful CLI test suite responsive and fail-bounded on variable Windows runner I/O.
