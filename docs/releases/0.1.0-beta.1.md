# Useful 0.1.0-beta.1 release-note draft

> **UNRELEASED / NOT FOR PRODUCTION.** This file is a release-note template, not a download page,
> test receipt, signed-release claim, or announcement that a GitHub Release exists.

## Candidate scope

- Intended workflow scope: `source-agent-kit` (non-desktop prerelease).
- The candidate asset set is limited to public-source evidence, the Agent Kit, SBOM, provenance,
  checksums, and legal notices. It contains no desktop binaries, installers, portable packages,
  update feed, code-signing/notarization claim, or supported-platform claim.
- Useful combines local utilities, video trimming, Windows process inspection, software sources,
  and local settings in one desktop host.
- The allowlisted Action runtime has JSON CLI and local stdio MCP entry points.
- Third-party `.useful` tooling covers validation, packaging, publisher signatures, and explicit
  artifact/publisher pins.
- Stable, beta, and nightly channel contracts are implemented; no production feed is asserted.
- Feedback bundles are saved only to a user-selected local path and are never uploaded
  automatically.
- The Agent Kit builder keeps `publicationAuthorized=false`; a separately recorded workflow Owner
  gate authorizes publication without changing that builder field.

## Security and distribution boundaries

- Plugin and Action capabilities remain explicit and fail closed.
- Development signing material cannot stand in for production trust.
- Failed installs or updates preserve evidence and do not become a pass through selective reruns.
- Portable Full remains blocked from public distribution until its exact GPL corresponding-source
  and license evidence has been approved.
