# Useful 0.1.0-beta.3 source and Agent Kit preview

This prerelease contains source code and the cross-platform Agent Kit. It does not contain desktop
binaries, installers, portable packages, or a production update feed.

## Highlights

- 36 built-in Actions are available through the JSON CLI and local stdio MCP server; MCP exposes
  four additional discovery helpers.
- Agent setup plans cover Codex, Claude Code, Claude Desktop, and explicit `mcpServers` JSON hosts
  without writing host configuration or executing generated commands.
- The Agent Kit dependency closure uses patched JavaScript packages, including `fast-uri 3.1.5`.
- Office actions remain local-only, and Computer Use remains a disabled safety contract with no
  executable provider or registered Action/MCP surface.
- The source-only publication job now installs its frozen dependency graph before revalidating the
  exact public-source snapshot at the protected `release` environment gate.

## Boundaries

- No signed desktop installer or supported-platform claim is included.
- The Agent Kit builder records `publicationAuthorized=false`; the controlled GitHub workflow stores
  the separate Owner approval and exact tag/commit evidence.
- Linux desktop dependencies, including the GTK stack, are outside this prerelease scope.
- Portable Full remains blocked until its exact GPL corresponding-source and license evidence is
  approved.

The GitHub Release is the authoritative record for the published asset list, checksums, SBOM, and
provenance attached to this tag.
