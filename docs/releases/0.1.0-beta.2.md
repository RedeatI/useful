# Useful 0.1.0-beta.2 source and Agent Kit preview

This file describes the intended non-desktop prerelease scope. The authoritative publication state,
asset list, hashes, and generated notes are the records attached to the matching GitHub Release.

## Scope

- Workflow scope: `source-agent-kit` (non-desktop prerelease).
- Assets are limited to public-source evidence, the Agent Kit, CycloneDX SBOM, provenance,
  checksums, and legal notices.
- No desktop binaries, installers, portable packages, update feed, code-signing/notarization claim,
  or supported-platform claim are included.
- The allowlisted Action runtime exposes JSON CLI and local stdio MCP entry points.
- Agent setup plans cover Codex, Claude Code, Claude Desktop, and explicit `mcpServers` JSON hosts;
  they do not write host configuration or execute generated commands.
- The Computer Use package is a disabled-by-default safety contract only. It has no executable
  provider and is not registered as an Action or MCP tool.
- The Agent Kit builder keeps `publicationAuthorized=false`; the controlled workflow records a
  separate Owner authorization without changing that field.

## Security and distribution boundaries

- Plugin and Action capabilities remain explicit and fail closed.
- Development signing material cannot stand in for production trust.
- Failed installs or updates preserve evidence and do not become a pass through selective reruns.
- Portable Full remains blocked from public distribution until its exact GPL corresponding-source
  and license evidence has been approved.

See [TEST-MATRIX.md](../TEST-MATRIX.md), [KNOWN-LIMITATIONS.md](../KNOWN-LIMITATIONS.md), and the
matching GitHub Release for the exact candidate evidence.
